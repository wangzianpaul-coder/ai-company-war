## Architecture Boundary

- `StartProjectCommand` and `AdvanceQuarterCommand` are payload-free nominal typed subclasses of `GameCommand`. Do not create a generic payload, queue, dispatcher, command bus or registry.
- `SimulationEngine` and `TickResult` are typed `RefCounted` scripts inside `simulation/`. They do not depend on Application, UI, SceneTree, nodes, files, time, frame delta, random APIs or persistence.
- Every Engine operation begins from a deep, independent `GameState` copy. The input object graph is never mutated.
- Start-project executes only `ProjectSystem.start_project` on the working copy.
- Advance-quarter executes exactly three explicit months in stable `ProjectSystem.advance_month → FinanceSystem.settle_month → SimulationClock.advance_month` order. It appends successful effect batches in that exact call order.
- If any Project, Finance or Clock step fails, `TickResult` exposes neither a working state nor effects. The caller's complete input state remains unchanged.
- A successful `TickResult` contains an independent resulting state and an immutable-by-interface ordered contribution sequence. Getters must not expose a mutable internal array or a mutable state object owned by the result.
- `GameSession` is a typed Application-layer `RefCounted`. It deep-copies constructor input, exclusively owns the committed active state, explicitly accepts only the two concrete command types, invokes the matching Engine operation and replaces active state only after complete success.
- After a successful atomic commit, `GameSession` emits exactly one typed committed-result signal carrying the new read-only `DashboardViewModel`. Rejected commands emit nothing. This is the local G1 form of the handoff's standard committed-notification chain, not a global event bus.
- Null, base `GameCommand` or any unknown subtype returns the existing typed `CommandResult` failure and changes neither committed state, last committed contributions nor the current view model.
- `GameSession` does not expose its mutable active `GameState`. Tests may request an independent typed snapshot; UI receives only a `DashboardViewModel`.
- `DashboardViewModel` contains and accepts typed primitives and display strings only. `GameSession` reads its own committed snapshot plus the same ordered contributions returned by the Engine, derives the primitive display values and constructs the view model.
- `GameSession` aggregates the explanation only from stable contribution reason/metric/unit fields. Neither it nor the view model may rerun Finance/Project formulas, invent effects, use a Dictionary/Variant payload or sort away source order.
- `ui/screens/dashboard.gd` depends only on `GameSession`, `DashboardViewModel`, `StartProjectCommand`, `AdvanceQuarterCommand` and UI types. It connects once to the typed committed-result signal; its callback only constructs and submits one allowed command, while initial setup and committed notifications refresh labels from a new view model.
- Dashboard code never preloads Runtime State, System, Engine or Effect types; never calls `_commit_*`, `advance_month*` or `settle_month`; and never changes cash, revenue, cost, progress or clock directly.
- `main.gd` is the Composition Root. It may construct the explicitly named `DEMO_*` Company/Project/GameState fixture and inject it, but it does not call a Simulation System/Engine, interpret effects or contain button callbacks.
- The fixed demo values are a narrow G1 end-to-end fixture, not a Content Definition, Balance registry or general new-game framework.
- New UI uses Anchor and Container layout. Existing absolute-offset debt must not be extended.
- No global event bus, Autoload, persistence, RNG, third-party framework or cross-system generic rollback abstraction.

function Get-AiWarPreHandoffHistory([string]$aiWarHistoryHead) {
    $aiWarHistoryCommits = @(
        git -C $aiWarProject rev-list --reverse "$aiWarPinnedBase..$aiWarHistoryHead"
    )
    $aiWarHistoryExit = $LASTEXITCODE
    $aiWarHistoryCountOutput = @(
        git -C $aiWarProject rev-list --count "$aiWarPinnedBase..$aiWarHistoryHead"
    )
    $aiWarHistoryCountExit = $LASTEXITCODE
    if ($aiWarHistoryExit -ne 0 -or $aiWarHistoryCountExit -ne 0) {
        throw 'Unable to inspect TP-012 pre-handoff history'
    }
    $aiWarHistoryCount = [int](($aiWarHistoryCountOutput -join '').Trim())
    if ($aiWarHistoryCount -lt 1 -or $aiWarHistoryCount -ne $aiWarHistoryCommits.Count) {
        throw 'TP-012 pre-handoff history has an invalid commit count'
    }

    $aiWarPreviousCommit = $aiWarPinnedBase
    for ($aiWarHistoryIndex = 0; $aiWarHistoryIndex -lt $aiWarHistoryCommits.Count; $aiWarHistoryIndex++) {
        $aiWarHistoryCommit = $aiWarHistoryCommits[$aiWarHistoryIndex]
        $aiWarHistoryParentsOutput = @(git -C $aiWarProject show -s --format=%P $aiWarHistoryCommit)
        $aiWarHistoryParentsExit = $LASTEXITCODE
        $aiWarHistorySubjectOutput = @(git -C $aiWarProject log -1 --format=%s $aiWarHistoryCommit)
        $aiWarHistorySubjectExit = $LASTEXITCODE
        if ($aiWarHistoryParentsExit -ne 0 -or $aiWarHistorySubjectExit -ne 0) {
            throw "Unable to inspect TP-012 commit: $aiWarHistoryCommit"
        }
        $aiWarHistoryParents = ($aiWarHistoryParentsOutput -join '').Trim()
        $aiWarHistorySubject = ($aiWarHistorySubjectOutput -join '').Trim()
        if ($aiWarHistoryParents -ne $aiWarPreviousCommit) {
            throw "TP-012 history is not a single-parent direct chain at: $aiWarHistoryCommit"
        }

        if ($aiWarHistoryIndex -eq 0) {
            if ($aiWarHistorySubject -ne $aiWarPinnedStartSubject) {
                throw 'TP-012 starting handoff subject changed'
            }
        } else {
            $aiWarHistoryPaths = @(
                git -C $aiWarProject diff-tree --no-commit-id --name-only -r $aiWarHistoryCommit
            )
            $aiWarHistoryPathsExit = $LASTEXITCODE
            $aiWarHistoryDeletedPaths = @(
                git -C $aiWarProject diff-tree --no-commit-id --name-only --diff-filter=D -r $aiWarHistoryCommit
            )
            $aiWarHistoryDeletedExit = $LASTEXITCODE
            if (
                $aiWarHistoryPathsExit -ne 0 -or
                $aiWarHistoryDeletedExit -ne 0 -or
                $aiWarHistoryPaths.Count -eq 0
            ) {
                throw "Unable to inspect TP-012 implementation/fix commit: $aiWarHistoryCommit"
            }
            if ($aiWarHistoryDeletedPaths.Count -ne 0) {
                throw "TP-012 implementation/fix commit deletes path(s): $aiWarHistoryCommit"
            }
            foreach ($aiWarHistoryPath in $aiWarHistoryPaths) {
                if ($aiWarImplementationAllowedPaths -notcontains $aiWarHistoryPath) {
                    throw "TP-012 implementation/fix path is outside the allowlist: $aiWarHistoryPath"
                }
            }
            if ($aiWarHistoryIndex -eq 1) {
                foreach ($aiWarRequiredPath in $aiWarImplementationRequiredPaths) {
                    if ($aiWarHistoryPaths -notcontains $aiWarRequiredPath) {
                        throw "Initial TP-012 implementation commit is missing required path: $aiWarRequiredPath"
                    }
                }
            }
        }
        $aiWarPreviousCommit = $aiWarHistoryCommit
    }

    return @($aiWarHistoryCommits)
}
